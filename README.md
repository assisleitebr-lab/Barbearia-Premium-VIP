# ✂️ Barbearia VIP - Sistema de Agendamentos & Gestão

Aplicação Web moderna e progressiva (PWA) desenvolvida para barbearias, permitindo atendimento dual (Modo Cliente e Modo Administrador).

## 🚀 Funcionalidades
- **Modo Cliente**: Identificação por nome, seleção de barbeiros com fotos, escolha de serviços, marcação de data/horário e checkout com pagamento simulado via **PIX**. Cada cliente possui uma aba privada para ver apenas os seus próprios agendamentos.
- **Painel Administrativo**: Acesso protegido por senha mestra (`1234`), listagem de todos os agendamentos recebidos, controle dinâmico do status do PIX (**Pendente ⏳** ou **Pago ✅**), métricas de faturamento e cadastro de novos profissionais na equipe.
- **PWA (Progressive Web App)**: Pronto para ser instalado diretamente na tela inicial de telemóveis e computadores.

## 🛠️ Tecnologias Utilizadas
- HTML5, CSS3 & JavaScript Moderno (ES6+)
- Tailwind CSS (Interface responsiva e elegante em modo escuro)
- Lucide Icons
- LocalStorage para persistência e gestão de estado local
